# 有限会社ふもと旅館 募集サイト

有限会社ふもと旅館の採用LP制作プロジェクトです。

## ドキュメント

- `AGENTS.md`: AIが作業するときのルールと参照順
- `CLAUDE.md`: Claude向けの入口
- `docs/PROJECT_SPEC.md`: サイトの現在仕様
- `docs/DEVELOPMENT.md`: 実装・SCSS・コンポーネント規約
- `docs/UI_SPEC.md`: メニューなどのUI動作仕様
- `docs/RELEASE.md`: デモ・本番・SEO・公開手順
- `docs/templates/`: SEO確認用テンプレート
- `docs/history/`: 採用技術などの判断履歴

各分野の正本は上記の対応ファイルです。概要・実装・UI・公開の仕様を別ファイルへ重複して記載しません。
