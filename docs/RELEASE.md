# 公開・環境仕様

## 環境

| 環境 | URL | 検索エンジン |
| --- | --- | --- |
| デモ | `https://demo-recruit-fumoto-ryokan.tuna-pic.co.jp/` | `noindex, nofollow` |
| 本番 | `https://recruit.fumoto-ryokan.jp/` | インデックス対象 |

## SEO

- canonicalとOGP URLは本番URLを基準にする
- デモではrobotsメタと`robots.txt`の両方でクロールを制限する
- 本番公開前に`title`、`description`、OGP、favicon、canonicalを確認する
- `robots.txt`とサイトマップを本番公開前に確認する
- デモと本番の切り替えはビルド時の環境設定で管理する
- 環境変数名とビルドスクリプトはAstro初期セットアップ時に決定する

## ビルド

```bash
npm run build
```

- 静的ビルド成果物は`dist/`へ出力する
- デモと本番は、それぞれ正しい環境設定でビルドする
- 公開前にビルドエラー、リンク切れ、メタ情報を確認する

## FTP公開

- `dist/`の中身だけを公開ディレクトリへアップロードする
- `src/`、`node_modules/`、設定ファイルはアップロードしない
- 既存公開ファイルを置き換える前に、サーバー側の配置を確認する

## 応募導線

- 現段階では`mailto:`リンクを使用する
- メールアドレスは提供後に設定する
- `mailto:`は利用者のメールアプリを起動する方式で、サーバー側の送信処理は持たない

## 更新方法

- CMSは現時点では導入しない
- 原稿変更時はソースを修正し、再ビルドしてFTPで更新する
- 更新頻度や更新担当者の要件が変わった時点でCMSを再検討する
