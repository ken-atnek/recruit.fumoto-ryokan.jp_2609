# UI動作仕様

## ページ内ナビゲーション

- ナビゲーションはLP内の各セクションへ移動する
- 各セクションへ固有の`id`を付ける
- URLにハッシュが残っても問題ない構造にする
- JavaScriptによる固定値のスクロール補正は行わない

## モバイルメニュー

- 操作用の`button`は1つだけ配置する
- `aria-controls`、`aria-expanded`、内容が分かる`aria-label`を付ける
- メニュー表示中は背景スクロールを抑止する
- メニュー内リンク、Escapeキー、外側クリックで閉じる
- 表示状態はクラスと`aria-expanded`を同期して管理する
- JavaScriptが動かない場合でも主要リンクへ到達できる構造を優先する

## 応募ボタン

- PCファーストビュー右上に円形ボタンを配置する
- LP末尾にも応募CTAを配置する
- リンク先と公開時の扱いは`docs/RELEASE.md`を参照する

## 画像の切り替え・アニメーション

### 社員寮の画像

初期実装では、指・マウス・キーボードで操作できるスライダーとして実装します。

- 前後操作と現在位置が分かる表示を用意する
- JavaScriptが無効な場合も、少なくとも先頭画像を表示する
- 画像の差し替えを想定し、画像データと操作ロジックを分離する

### 写真アニメーション

Figmaの注記を基準に、以下を初期実装の対象とします。

- 対象写真のゆっくりしたフェード切り替え
- 写真列の左右へのゆっくりしたスライド

具体的な秒数、イージング、切り替え間隔は実装時にデザインを確認して決定します。本文の閲覧や操作を妨げない範囲に留め、`prefers-reduced-motion`に対応します。
